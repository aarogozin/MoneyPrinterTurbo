## Функциональные особенности 🎯

- [x] Полная **архитектура MVC**, понятная структура кода, простота обслуживания, поддержка `API` и `веб-интерфейса`

- [x] Поддержка различных разрешений **видео высокой четкости**
  - [x] Вертикальное 9:16, `1080x1920`
  - [x] Горизонтальное 16:9, `1920x1080`

- [x] Поддержка **генерации субтитров** с возможностью настройки `шрифта`, `положения`, `цвета`, `размера` и `обводки`
- [x] Поддержка **фоновой музыки** (случайный выбор или указание файла, настройка громкости)
- [x] Видеоматериалы высокого разрешения и **без авторских прав** (роялти-фри), также можно использовать собственные **локальные материалы**
- [x] Поддержка интеграции с моделями ИИ от **OpenAI**, **AIHubMix**, **Moonshot**, **Azure**, **gpt4free**, **one-api**, **Qwen (Tongyi Qianwen)**, **Google Gemini**, **Ollama**, **DeepSeek**, **MiniMax**, **ERNIE (Baidu)**, **Pollinations**, **ModelScope** и др.

## Системные требования 📦

- Рекомендуемые ОС: Windows 10, macOS 11.0 или выше, либо популярные дистрибутивы Linux
- Наличие GPU не обязательно, но если вы хотите использовать локальную транскрипцию, ускорить обработку видео или получить более плавную пакетную генерацию, рекомендуется видеокарта с видеопамятью.

| Компонент | Минимальная конфигурация | Рекомендуемая конфигурация | Идеальная конфигурация |
| ---- | -------- | --------------- | --------------- |
| CPU  | 4 ядра     | 6–8 ядер       | 8 ядер и более      |
| RAM  | 4 ГБ     | 8 ГБ            | 16 ГБ и более    |
| GPU  | Не требуется   | 4 ГБ видеопамяти и более | 8 ГБ видеопамяти и более |

- Если вы в основном используете облачные LLM, облачный TTS и онлайн-источники материалов, CPU и оперативная память важнее, чем GPU.
- Если вы включите `faster-whisper`, пакетную генерацию или ресурсоемкую локальную обработку, GPU заметно повысит производительность.

## Установка и развертывание 📥

### Предупреждения

- Старайтесь избегать путей, содержащих не-ASCII символы (кириллицу, китайские иероглифы), во избежание непредвиденных проблем.
- Убедитесь, что ваше интернет-соединение стабильно (для VPN может потребоваться включить глобальный режим).

#### ① Клонирование репозитория

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

#### ② Редактирование конфигурационного файла (необязательно, можно настроить в WebUI после запуска)

- Скопируйте файл `config.example.toml` и назовите его `config.toml`
- Следуя инструкциям в `config.toml`, настройте ключи `pexels_api_keys` и `llm_provider`, а также соответствующие API-ключи для выбранного провайдера.
- Если вы хотите использовать рекомендуемый ИИ-провайдер, вы можете установить `llm_provider` в значение `aihubmix` и указать соответствующий API-ключ.

### Развертывание через Docker 🐳

#### ① Запуск Docker

Если Docker еще не установлен, установите его с официального сайта: https://www.docker.com/products/docker-desktop/

Для пользователей Windows см. документацию Microsoft:

1. https://learn.microsoft.com/ru-ru/windows/wsl/install
2. https://learn.microsoft.com/ru-ru/windows/wsl/tutorials/wsl-containers

```shell
cd MoneyPrinterTurbo
docker-compose up
```

> Примечание: Последние версии Docker автоматически устанавливают docker compose в виде плагина, поэтому команда запуска изменена на `docker compose up`.

#### ② Веб-интерфейс

Откройте браузер и перейдите на http://127.0.0.1:8501

#### ③ Документация API

Откройте браузер и перейдите на http://127.0.0.1:8080/docs или http://127.0.0.1:8080/redoc

### Ручное развертывание 📦

> Видео-уроки (на китайском языке)

- Полная демонстрация работы: https://v.douyin.com/iFhnwsKY/
- Развертывание на Windows: https://v.douyin.com/iFyjoW3M

#### ① Создание виртуального окружения

Рекомендуется использовать [uv](https://docs.astral.sh/uv/) для управления окружением Python и зависимостями, по умолчанию используется Python `3.11`

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Если вы пока не используете `uv`, вы можете продолжать использовать `venv + pip`

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Описание:

- `pyproject.toml` — основной файл описания зависимостей.
- `uv.lock` — файл блокировки версий, рекомендуется использовать `uv sync --frozen`.
- `requirements.txt` сохранен только для совместимости со старым методом установки через `pip`.

#### ② Запуск веб-интерфейса 🌐

Обратите внимание, что следующие команды необходимо выполнять в **корневой директории** проекта MoneyPrinterTurbo.

###### Windows

```powershell
.\webui.bat
```

В CMD также можно запустить `webui.bat`.
`webui.bat` сначала ищет `.venv` проекта или встроенный Python. Если они не найдены, но установлен `uv`, автоматически запустится `uv run streamlit`.
Чтобы разрешить доступ к WebUI другим устройствам в локальной сети, перед запуском `webui.bat` выполните команду `set MPT_WEBUI_HOST=0.0.0.0`.

###### MacOS или Linux

```shell
uv run streamlit run ./webui/Main.py --browser.gatherUsageStats=False
```

Если вы уже вручную активировали виртуальное окружение, можно запустить:

```shell
sh webui.sh
```

После запуска автоматически откроется браузер (если страница пустая, смените браузер на Chrome или Edge).

#### ③ Запуск API-сервиса 🚀

```shell
uv run python main.py
```

Если вы уже вручную активировали виртуальное окружение, можно запустить:

```shell
python main.py
```

## Синтез речи 🗣

Список всех поддерживаемых голосов доступен в файле: [Список голосов](./docs/voice-list.txt)

По умолчанию используется бесплатный **Edge TTS** (не требует API-ключа). В веб-интерфейсе он отображается как **«Azure TTS V1»** (это тот же самый сервис). Вы можете настроить `voice_name` в `config.toml` или выбрать его из выпадающего списка голосов в веб-интерфейсе.

> **Примечание:** «Azure TTS V1» (бесплатный Edge TTS) и «Azure TTS V2» (платный Azure Speech SDK) — это две разные опции. API-ключ нужен только для V2.

Для использования более качественных голосов **Azure TTS V2** настройте учетные данные в `config.toml`:

```toml
[azure]
speech_key = "your-azure-speech-key"
speech_region = "eastus"
```

Azure TTS V2 требует активной подписки [Azure Speech Services](https://portal.azure.com/). 9 новых голосов Azure, добавленных в версии v1.1.2, звучат более естественно, чем Edge TTS.

## Генерация субтитров 📜

Поддерживается 2 способа генерации субтитров:

- **edge**: использование временных меток, возвращаемых Edge TTS. Работает быстро, не требует GPU и мощного железа, но тайминги для сложных предложений могут быть не совсем точными.
- **whisper**: использование локального `faster-whisper` для распознавания сгенерированного аудио и создания более точных временных меток для каждого слова. Работает медленнее (на CPU занимает от нескольких секунд до минуты в зависимости от размера модели), требует скачивания модели (`large-v3-turbo` около 250 МБ или `large-v3` около 3 ГБ), но обеспечивает лучшую точность субтитров независимо от TTS.

Вы можете переключить провайдера, изменив значение `subtitle_provider` в конфигурационном файле `config.toml`.

Рекомендуется использовать режим `edge`, а в случае неудовлетворительного качества переключаться на `whisper`.

> Примечание:
>
> 1. В режиме whisper требуется скачать модель с HuggingFace объемом около 3 ГБ, убедитесь в стабильности интернет-соединения.
> 2. Если поле оставлено пустым, субтитры генерироваться не будут.

> Поскольку во многих регионах доступ к HuggingFace ограничен, можно скачать модель `whisper-large-v3` по ссылкам ниже.

Ссылки для скачивания:

- Baidu Netdisk: https://pan.baidu.com/s/11h3Q6tsDtjQKTjUu3sc5cA?pwd=xjs9
- Quark Netdisk: https://pan.quark.cn/s/3ee3d991d64b

После скачивания распакуйте архив и поместите папку в `.\MoneyPrinterTurbo\models`.
Итоговый путь к файлам должен выглядеть следующим образом: `.\MoneyPrinterTurbo\models\whisper-large-v3`

```
MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json
```

## Часто задаваемые вопросы 🤔

### ❓RuntimeError: No ffmpeg exe could be found

Обычно ffmpeg скачивается и обнаруживается автоматически.
Однако, если возникли проблемы с окружением и автоматическое скачивание не сработало, вы можете увидеть ошибку:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

В этом случае вы можете скачать ffmpeg с https://www.gyan.dev/ffmpeg/builds/, распаковать его и указать путь к файлу в переменной `ffmpeg_path`:

```toml
[app]
# Укажите реальный путь. Для Windows используйте двойной слэш \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

### ❓Ошибки, связанные с ImageMagick

> **В текущей версии ImageMagick больше не требуется.**
>
> После обновления проекта до **MoviePy 2.x** рендеринг субтитров выполняется с помощью библиотеки **Pillow** и больше не зависит от ImageMagick. Если вы видите эту ошибку, вы используете старую версию кода. Обновите проект, выполнив `git pull` (или запустив `update.bat` на Windows).

### ❓OSError: [Errno 24] Too many open files

Эта проблема связана с ограничением системы на количество одновременно открытых файлов. Решается увеличением лимита в системе.

Проверить текущий лимит:

```shell
ulimit -n
```

Если значение слишком мало, увеличьте его, например:

```shell
ulimit -n 10240
```

outgoing traffic has been disabled.
