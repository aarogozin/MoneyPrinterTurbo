# Руководство по развертыванию Docker с поддержкой GPU

В данном документе описывается, как использовать графический процессор (GPU) для ускорения генерации субтитров с помощью `faster-whisper`, что значительно повышает скорость обработки.

## Зачем нужно ускорение на GPU

Единственным этапом глубокого обучения в MoneyPrinterTurbo является **распознавание речи faster-whisper** (преобразование аудио в субтитры с временными метками).

- **Режим CPU** (по умолчанию): генерация субтитров с использованием модели `large-v3` происходит медленно.
- **Режим GPU**: использование видеокарты NVIDIA и технологии CUDA повышает скорость в **5–10 раз**.

> Примечание: Другие этапы проекта (генерация сценария, синтез аудио, редактирование видео) не связаны с глубоким обучением. GPU ускоряет исключительно генерацию субтитров.

## Варианты развертывания

Проект поддерживает два способа развертывания в Docker. **Развертывание на CPU по умолчанию остается полностью работоспособным и не требует изменений**:

### Развертывание на CPU (по умолчанию, без изменений)

```bash
docker compose up -d
```

Использует стандартный `Dockerfile` (`python:3.11-slim-bullseye`), наличие графического процессора не требуется.

### Развертывание на GPU (для пользователей видеокарт NVIDIA)

```bash
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d
```

Использует `Dockerfile.gpu` (`nvidia/cuda:12.1.1-cudnn8-runtime-ubuntu22.04`) и монтирует GPU для сервиса API.

## Предварительные требования для GPU

### 1. Требования к оборудованию

- Видеокарта NVIDIA (рекомендуется от 6 ГБ видеопамяти)
- Модель `large-v3` на GPU при точности `float16` занимает около 1.5 ГБ видеопамяти.

### 2. Требования к ПО

- **Драйвер NVIDIA**: Рекомендуется последняя версия. Выполните команду `nvidia-smi` для проверки.
- **Docker Desktop**
- **NVIDIA Container Toolkit**: Выполните команду `docker info`, чтобы убедиться, что `nvidia` присутствует в списке Runtimes.

### 3. Проверка окружения

```bash
# Убедитесь, что драйвер NVIDIA работает нормально
nvidia-smi

# Убедитесь, что Docker поддерживает GPU (nvidia должна быть в списке Runtimes)
docker info | findstr nvidia
```

Если рантайм `nvidia` отсутствует, необходимо сначала установить [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html).

## Настройка Whisper для использования GPU

Задайте следующие параметры в файле `config.toml`:

```toml
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3"
device = "cuda"           # Использовать GPU (для CPU укажите "cpu")
compute_type = "float16"  # Для GPU рекомендуется float16 (для CPU укажите "int8")
```

## Описание файлов конфигурации

| Файл | Назначение |
|---|---|
| `Dockerfile` | Образ для CPU по умолчанию (оригинальный, без изменений) |
| `Dockerfile.gpu` | Образ для GPU (новый, на базе NVIDIA CUDA) |
| `docker-compose.yml` | Конфигурация CPU по умолчанию (оригинальная, без изменений) |
| `docker-compose.gpu.yml` | Переопределение настроек для развертывания с GPU (новый) |

## Шаги развертывания с GPU

### Шаг 1: Скачивание базового образа CUDA

```bash
docker pull nvidia/cuda:12.1.1-cudnn8-runtime-ubuntu22.04
```

> Если вы используете зеркала для ускорения (например, Aliyun), они могут возвращать ошибку 403 при скачивании `nvidia/cuda`. Убедитесь, что можете скачивать образы напрямую с Docker Hub.

### Шаг 2: Изменение config.toml

Укажите `subtitle_provider = "whisper"` и `device = "cuda"`, как описано выше.

### Шаг 3: Сборка и запуск

```bash
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d --build
```

### Шаг 4: Проверка работы GPU

```bash
docker exec -it moneyprinterturbo-api nvidia-smi
```

Если вы увидели информацию о видеокарте, значит, GPU успешно проброшен в контейнер.

## Рекомендации по видеопамяти и параллельным задачам

| Объем видеопамяти GPU | Рекомендуемое макс. число параллельных задач |
|---|---|
| 4 ГБ | 1-2 |
| 6 ГБ | 2-3 |
| 8 ГБ | 3-4 |
| 12 ГБ+ | 5 |

Вы можете управлять лимитом параллельных задач с помощью параметра `max_concurrent_tasks` в файле `config.toml`.

## Устранение неполадок

### Проблема 1: Ошибка скачивания образа (403 Forbidden)

Зеркало Aliyun возвращает 403 для `nvidia/cuda`. Решение:
- Настройте другие доступные зеркала образов.
- Либо скачайте образ напрямую: `docker pull nvidia/cuda:12.1.1-cudnn8-runtime-ubuntu22.04`

### Проблема 2: Ошибка pip при установке `Cannot uninstall blinker`

Системный пакет `blinker` в Ubuntu 22.04 установлен через `distutils`, поэтому pip не может его удалить. В `Dockerfile.gpu` эта проблема решена предварительным выполнением команды `apt-get remove -y python3-blinker`.

### Проблема 3: Утилита `nvidia-smi` внутри контейнера не видит GPU

- Убедитесь, что на хост-машине установлен NVIDIA Container Toolkit.
- Проверьте, что в выводе команды `docker info` рантаймы содержат `nvidia`.
- Убедитесь, что для запуска использовалась команда развертывания с GPU: `docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d`

### Проблема 4: Whisper выдает ошибку CUDA

- Убедитесь, что в `config.toml` указано `device = "cuda"` (регистрозависимо, не `"CPU"`).
- Убедитесь, что указано `compute_type = "float16"`.
- Убедитесь, что указано `subtitle_provider = "whisper"`.
